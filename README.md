# 高中英语3500词训练场 —— E门出品

Senior High English 3500-Word Trainer — E.D. STUDIO

一个**完全离线**、单文件的平板电脑英语词汇训练应用，面向高中英语 3500 词。

## 功能
- **学生端**：用「姓名 + 学号」登录（学号即密码），按单元刷词、填空、选择题训练，自动记录已掌握 / 易错词与正答率。
- **管理端**：默认密码 `123456`（可在后台修改；忘记可一键重置）。查看全班进度、正答率、高频易错词。
- **名单管理**：支持粘贴（姓名+学号）/ `.xlsx` / `.csv` 上传，智能识别姓名与学号列。
- **云端同步**：可接入 Supabase 实现跨设备同步（需自行配置 Project URL 与 anon key）。
- **一键导出易错词（Word / PPT）**：在管理后台「总览」页点击「导出 Word + PPT」，自动整合**全部学生**进度中的易错词，连同对应的「表达拓展」（短语 / 近义 / 续写句 / 应用文句 / 记忆技巧），生成 Word 与 PowerPoint 两份文件直接下载，用于课堂讲评或打印。

## 使用
直接用浏览器打开 `index.html` 即可（建议 Safari / Chrome，可「添加到主屏幕」当作 App 使用）。
导出的 Word / PPT 字体：中文 华文楷体（STKaiti），英文 Times New Roman。

## 部署（GitHub Pages）
本目录即为 GitHub Pages 站点根目录：`index.html` 为入口。
在仓库 Settings → Pages 选择 `main` 分支 `/root` 即可发布，获得一个可在任意电脑点击打开的链接。
